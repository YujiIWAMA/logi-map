関連図のヒント

実習中に「どう図にすればいい？」と迷ったときに見返すページです。図を描く作業はPC版で行いましょう。

描く順番

1患者さんを起点に置く

関連図の主体は病気ではなく患者さんです。まず中心（または起点）に患者さんを置き、そこから情報を広げます。

自分に問う：この情報は「この患者さん」にとってどんな意味がある？ 教科書の病態図を写していない？
2集めた情報を分類する

情報をいきなり矢印でつながず、まず種類ごとに整理します。

例：疾患・治療／検査データ／患者さんの言葉（主観）／観察した事実（客観）／生活・家族・環境

自分に問う：その情報は「誰が言ったこと」「何で確かめたこと」？ 主観と客観が混ざっていない？
3情報に意味づけをする

データをそのまま置くだけでは図になりません。「正常か・異常か」「なぜそうなっているか」を一言で添えます。

自分に問う：「Hb 9.2」だけで終わっていない？ それは何を示していて、患者さんの生活にどう影響する？
4原因から結果へ、省略せずにつなぐ

いちばん多いつまずきは、原因と結果の間を飛ばしてしまうことです。矢印1本の間に「なぜ？」が入るなら、その間を書き出します。

飛ばしすぎの例：心不全 → 転倒転落リスク状態

間を埋めると、たとえば次のようになります。

  1. 心不全
  2. 心拍出量の低下
  3. 労作時の息切れ・倦怠感、活動量の低下
  4. 下肢筋力の低下
  5. （＋利尿薬による夜間頻尿 → 夜間のトイレ歩行）
  6. 転倒転落リスク状態
自分に問う：矢印1本ごとに「だから」とつなげて声に出して読める？ 読めないところに中間項目が隠れている。
5PESでまとめる

つながりが見えたら、看護問題をPESの形で整理します。関連図・アセスメント・看護計画は、この形でつながります。

P（問題）：患者さんに起きている／起こりうる状態
E（原因・関連因子）：その状態を引き起こしているもの
S（症状・徴候）：Pがあると判断した根拠となるデータ
自分に問う：Pの根拠になるSは図の中にある？ Eは看護で働きかけられるものになっている？（「心不全」そのものは看護で取り除けない）
6看護計画につなげ、優先順位をつける

看護計画はEに働きかけることで組み立てます。図の中で複数の問題につながっているEは、優先度が高い手がかりになります。

自分に問う：計画の各項目は、図のどのEを減らす・支えるもの？ 図とつながらない計画が混ざっていない？
